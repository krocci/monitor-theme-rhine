# Rhine Observation project

- This repository is the primary workspace for Rhine Observation development.
- Start with README.md, docs/PROJECT.md, docs/DECISIONS.md and docs/ROADMAP.md.
- When earlier discussion or deployment evidence is relevant, read local/README.md
  and select the corresponding report. Do not load the entire local archive.
- Keep local/ private and ignored by Git. It contains chat exports, attachments,
  personal deployment records and historical tools. Never force-add or publish it.
- Treat local/legacy/ as a historical snapshot, not another source tree to edit.
  Make application changes in this repository's src/, scripts/ and tests/.
- Preserve the committed package-lock.json and Node.js 24.19.0 baseline.
  Dependency upgrades require a separate reason and verification.
- Keep the theme two-dimensional. Preserve the three views, native site title,
  continuous wheel interaction, solid overlaid curves and real data gaps.
- Read-only theme development does not authorize server, Access, Tunnel, DNS,
  hub, agent or credential changes. Use synthetic data for local development.
- Keep personal Access policy separate from reusable theme behavior.
- Distinguish historical acceptance, current local checks and actual browser
  acceptance. A Node benchmark or HTTP 200 does not prove browser performance.
- Run checks appropriate to a change. For a release, follow RELEASING.md and
  verify the final archive. Keep published tags and assets unchanged.
- Update docs/ROADMAP.md when a requirement is completed or its scope changes.
  Use Asia/Shanghai for dated project records.
