# Rhine Observation 独立项目

整理日期：2026-10-24，Asia/Shanghai。

## 已有功能

- 简报首页以二维档案阵列展示节点，支持跟随滚轮的连续移动、反向响应、惯性停靠、键盘导航和可暂停的 8 秒轮播。
- 卡片以名称、状态、分组为主要身份，使用方环展示 CPU、内存、磁盘和底部实时速率；右侧是最近一小时的简略资源趋势，保留真实断档。
- 节点索引支持搜索、分组、状态与关注筛选；显式入口初始化对应筛选，详情返回保留列表上下文；关闭按钮、Esc 和点击浮窗外关闭。
- 节点详情采用紧凑信息区，资源趋势和网络探测优先展示图表。
- 站标题读取 Monitor 的 `site_name`，缺值回退到 `Monitor`。
- 网络探测默认使用不同颜色的实线同图叠加，支持图例显隐和共享时间刷选。
- 0.1.4 每条探测最多使用三条 SVG 路径绘制密集历史；保留真实断档、极值、孤立成功样本，缩放和提示框使用原始采样。
- 连接恢复保留 HTTP 回退、有上限的 WebSocket 重连，以及失权时清除私有快照的行为。

具体设计约定见 [DECISIONS.md](DECISIONS.md)。后台管理仍使用 Monitor 原生界面；主题不提供服务器写入或远程控制。

## 验证边界

迁移前记录显示：0.1.4 的应用测试、19 项工具测试、18 项部署工具离线测试、构建、打包和服务器文件读回通过。发布包独立下载、公开源码重建包与固定安装包的校验一致。

0.1.4 的 Chrome 自动化被保存的浏览器权限设置拒绝，因此一天密集数据的实际绘制、缩放、提示框和操作流畅度仍待验证。Node 数据处理基准不能替代浏览器验收。0.1.3 的桌面交互检查和 0.1.2 的短时连接观察只代表对应历史版本。

公开仓库在迁移前没有启用 GitHub Actions。本机保留的 workflow 模板不代表远端 CI 已运行。迁移后的本地检查另记于本机迁移报告。

2026-10-24 的 `0.1.5` 已完成应用测试、24 项工具测试、lint、构建、打包及归档检查。正式构建在 Codex 内嵌浏览器中通过一天七线路、图例、削峰、共享时间刷选拖动、390px 窄屏和主题内减少动态效果检查。生产浏览器显示方环及真实一小时趋势，并确认“关注 → 关闭 → 节点索引”恢复全部节点；生产与演示静态资源分别逐文件读回。服务器、发布资产与浏览器证据分别记录，不以 HTTP 或 Node 基准替代客户端验收。物理设备、提示框滚动组合与长时连接仍按后续计划补验。
