# 静态建筑背景与视觉细化

日期：2026-10-27，Asia/Shanghai。本地实现与检查完成后，已随 0.1.6 发布并部署；最终产物和线上检查见 [发布记录](RELEASE-0.1.6.md)。下文保留设计阶段的验证基线。

## 设计范围

本次需求是改善背景和整体氛围。现有卡片交互继续保留，放弃 ASCII 背景方案，沿用纸色、细线、档案排版和少量铜橙强调色。仅修改背景与装饰样式，不改变站点名称、数据请求、节点选择、轮播、连续滚轮、图表或权限逻辑。

## 实现

- `src/assets/observation-field.svg`：3,130 字节的原创静态矢量背景；路径、渐变和网格均在文件内定义。
- `src/index.css`：使用现有 `.rhine-app::before` 承载背景，替换卡片下方的通用斜线底纹；细化页眉色标、档案定位线和页脚。
- `src/components/briefing.css`：补足 601 至 900 像素布局的卡片区域高度，修复原有堆叠下缘覆盖节点标题的问题；卡片尺寸、位置公式和变换保持不变。
- 900 像素及以下调整裁切，600 像素及以下采用独立构图。详情页降低背景不透明度，不改变紧凑布局。
- 装饰不接收指针事件，不加入可访问性树，不增加 DOM 节点、JavaScript、计时器、动画循环、模糊滤镜或远程资源。卡片本身的既有动画保持原样。

## 本次验证

使用固定 Node.js 24.19.0、既有锁文件与依赖。`npm test`、`npm run lint`、`npm run build` 均通过。锁文件 SHA-256 保持为 `cdeab81aaa898969c48028d4c2e1f35f25b0e6e4141a5816e03a878cdbc098f2`。

在本机内嵌 Chromium 浏览器中打开 Vite 正式构建预览，只连接 `127.0.0.1:9911` 的合成数据：

- 检查 320 / 390 / 768 / 1024 / 1440 像素视口，页面没有横向溢出；窄屏页眉色标避开站名。
- 补查 601 / 659 / 768 / 900 像素下的堆叠布局，卡片下缘距信息区标签约 51 至 58 像素，原有标题遮挡已消除。
- 实际滚轮操作能继续驱动卡片切换；上一个、下一个、索引筛选及详情导航可用。
- 桌面资源详情和窄屏网络详情可读，缺测断档仍在；离线、未上报节点继续显示原有状态与缺值。
- 320 像素下的超长站名自然换行，本机“减少动态效果”开关可用，背景始终没有动画。
- 检查期间未记录到浏览器控制台错误。截图、修改前备份和详细检查数据保存在被 Git 忽略的本地记录中。
