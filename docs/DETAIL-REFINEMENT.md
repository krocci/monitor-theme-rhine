# 详情页细化与文字黑条揭示

日期：2026-10-27，Asia/Shanghai。本地实现与检查完成后，已随 0.1.6 发布并部署；最终产物和线上检查见 [发布记录](RELEASE-0.1.6.md)。下文保留设计阶段的验证基线。

## 设计范围

在 [静态背景细化](VISUAL-REFINEMENT.md) 基础上优化节点详情，并加入原 RhineLabUI 演示中的文字黑条揭示效果。沿用纸色、近黑、铜橙和细线档案语言，维持紧凑布局；不引入三维场景、ASCII 背景或新依赖。

- 标题区采用轻纸色档案面板、铜色左线和 `NODE FILE` 标记，分组、状态、处理器、架构及上报时间保持真实含义。
- 选中标签使用近黑底与铜色底线，概况内的资源仪表和网络传输统一边框、标题与数值排版。
- 资源趋势与网络探测增加稳定的章节标题，图表使用轻纸色细框、铜色标题定位线和清楚的图例分隔。
- 720 像素及以下采用单列详情，避免中窄屏的并排面板挤压速率单位；小屏继续自然滚动。
- 数据请求、历史抽样、连续滚轮、卡片、实线叠加、缺测断档及权限逻辑保持原样。

## 黑条动画

参考并改写 `LBEILC/RhineLabUI` 的 `src/document-decryption.ts` 与对应样式：测量真实文字的各行，以近黑条覆盖，再从左向右露出原文。原文始终保留在 DOM 中，遮罩标记 `aria-hidden` 且不接收指针事件。

实现入口是 `src/components/useDocumentReveal.ts`，分别用于详情身份区、概况章节标题和历史章节标题：

- 只在内容进入时测量，先完成布局读取再创建遮罩。每个区域最多 24 行；通常一个节点详情只有 5 条遮罩。
- 单条位移动画 740 毫秒，错开 60 至 210 毫秒，最长 950 毫秒；使用浏览器 Web Animations 和 `transform`，不加入逐帧 JavaScript 循环。
- 动画完成后移除临时节点、取消动画并解除监听；另设 1,100 毫秒的单次兜底清理。离开内容、窗口调整、页面隐藏及动态偏好改变时清理。
- 不遮挡在线状态、实时数值、上报时间、按钮、图例或曲线。实时上报、历史范围变化、刷新历史和图例显隐不会触发重播。
- 本机减少动态效果开关与系统 `prefers-reduced-motion` 均可跳过动画；隐藏页面和不支持 Web Animations 的环境直接显示内容。

## 当前本地验证

使用固定 Node.js 24.19.0 与原有依赖：

- `npm test`、`npm run lint`、`npm run build` 通过。
- `npm run check:package` 通过，包含新增许可说明；仅在内存中构造和检查候选包，没有覆盖已发布归档。
- 锁文件 SHA-256 保持为 `cdeab81aaa898969c48028d4c2e1f35f25b0e6e4141a5816e03a878cdbc098f2`。

在本机内嵌 Chromium 中操作正式构建预览，仅连接本机合成数据：

- 检查 320 / 390 / 601 / 768 / 1024 / 1440 像素视口，概况及历史布局无页面横向溢出；在 601 像素处发现的并排挤压已通过单列断点修正。
- 实际捕捉到概况标题的 2 条遮罩、普通详情的 5 条遮罩，以及 320 像素长名称详情的 9 条遮罩，其中标题占 4 行；揭示结束后均清理为 0。
- 快速切换节点和标签后只保留当前内容的遮罩；一次历史标题动画在调整视口前为 1 条，调整后为 0。
- 本机减少动态效果开启后，切换资源与网络标签均为 0 条遮罩；恢复原设置后动画恢复。
- 多次实时上报后、历史范围切换及刷新后遮罩为 0。离线、未上报和无探测样本状态可读，资源图的真实断档保留。
- 一天七条合成线路的图例、显隐及削峰可操作；390 像素下图例换行、图表和页面滚动可用。这是此次样式回归检查，不替代 RH-01 的完整专项验收。
- 检查期间未记录到页面控制台错误或警告。
