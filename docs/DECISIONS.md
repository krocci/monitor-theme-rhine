# 已确认的设计与实现约定

整理自 2026-10-23 至 2026-10-24 的主题讨论。需求发生过修正，以下采用后续确认的方向；完整原话与来源行号保存在本机聊天导出中。

| 主题 | 最终约定 | 说明 |
|---|---|---|
| 视觉方向 | 纸色、细线、档案排版、近黑文字及少量铜橙强调色 | 保留档案终端风格，减少解释性小注释 |
| 二维范围 | DOM、CSS、SVG 为主，保留必要交互 | 早期三维建议已被二维方向替代，不恢复 Three.js、模型或开场音频 |
| 三个主要视图 | 节点简报、全部节点索引、单节点详情 | 简报强调简要信息，索引用于比较与选择，详情展示资源和探测 |
| 节点身份 | 移除前台 `N-00x` / `NODE xxx`，名称、状态与分组置顶 | 内部 ID、详情路由、关注绑定不变；底部集合位置计数继续保留 |
| 档案卡片 | 使用三层方环展示 CPU、内存与磁盘占用，配合精确数值 | 上下行显示速率；只限制几何绘制到 100%，文字保留实际比例；缺测显示 `--`，离线和过期来源明确 |
| 简报趋势 | 原 CPU 等大数值区改为最近一小时的 CPU、内存、上下行简图 | 上下行以实线同图叠加；仅请求选中节点，短时缓存、切换取消旧请求，保留真实缺测和孤立样本 |
| 后台 | 沿用 Monitor 原生后台 | 不把后台统一换肤纳入主题范围 |
| 站标题 | 直接读取 Monitor 的站点名称 | 不新增主题内独立站名；以文本渲染，缺值回退到 Monitor |
| 轮播进度 | 在主题现有细线上呈现 8 秒进度，可暂停 | 手动选择后重新计时；隐藏、失权、过期或打开浮窗时暂停 |
| 滚轮 | 持续输入立即影响档案位置，支持反向与惯性停靠 | 旧版“记录一次手势后播放整段动画并锁定输入”已被替代 |
| 输入边界 | 只在适用的桌面档案区域接管纵向滚轮 | 保留页面自然滚动、触屏、表单、缩放和减少动态效果 |
| 索引浮窗 | 支持点击外部关闭，也保留关闭按钮和 Esc | 面板内按下再拖到遮罩不触发误关闭 |
| 索引入口 | 普通索引与 `/` 初始化全部节点；关注和状态入口初始化对应筛选 | 显式入口同时重置搜索、分组、排序与滚动；从详情返回来源保留原列表上下文 |
| 详情布局 | 减少页头、仪表和留白占用，切换标签后直接看到主要图表 | 保持窄屏自然滚动 |
| 延迟曲线 | 不同颜色的实线在同图叠加，共用时间轴与 ms 纵轴 | 用户反对的是虚线叠加导致的混乱；后续已明确允许并要求同图比较 |
| 真实历史 | 超时和缺测保持断线，孤立成功样本仍可见 | 不把缺失改成零；窗口丢包使用服务端统计 |
| 密集曲线 | 减少绘图组件，简化时保留极值，缩放使用原始样本 | 不通过减少服务端采样或抹掉尖峰来掩盖性能问题 |
| 连接状态 | 保留真实过期、回退及失权提示 | 不通过隐藏错误来宣称稳定性修复 |
| Access | 属于部署者个人策略，不是主题依赖或通用默认值 | 主题开发与生产访问策略分别管理 |
| 价格与到期 | 作为后续可选展示，默认关闭，缺值不显示 | 尚未实现；界面开关不改变 Monitor API 的公开字段 |
| 许可与素材 | 保留 MIT 及上游来源，独立说明视觉参考 | 不将原作标志、截图、字体、模型或音效混入公开主题包 |

后续需求调整应同步修改本表和 [ROADMAP.md](ROADMAP.md)，避免重新引入已经被修正的旧方案。
