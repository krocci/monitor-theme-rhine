# Rhine Observation 0.1.6

日期：2026-10-27，Asia/Shanghai。

在既有纸色档案界面上增加静态建筑弧带、工程网格和铜色定位线，改善背景层次；素材库仅用于视觉参考，新增 SVG 自行绘制。修复 601 至 900 像素布局中堆叠卡片下缘遮挡节点标题的问题，保留卡片运动和连续滚轮交互。

节点详情统一为档案标题栏、深色选中标签以及细框资源、传输和图表面板；720 像素及以下采用单列详情。加入原 RhineLabUI 演示的逐行文字黑条揭示：约 0.8 至 0.95 秒结束，随后清理临时遮罩，不遮挡实时数值、状态、控件和曲线，不随数据刷新重播，尊重减少动态效果。上游 MIT 版权及许可已保留在 LICENSE 与 NOTICE。
